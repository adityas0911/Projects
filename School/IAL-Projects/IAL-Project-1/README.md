## Running the Project

1. **Download the Project Files**

   - Download the zip folder from [GitHub](https://github.com/adityas0911/IAL-Project-1).

2. **Unzip the Files**

   - Extract the contents of the zip folder.

3. **Install Dependencies**

   - Install any necessary dependencies/libraries as required by the project.

4. **Configure Settings**

   - In `./final/main.py`, set the following variables:

     - **bot_id (line 22):** Choose the bot to run (1 for bot_1, 2 for bot_2, 3 for bot_3, or 4 for bot_4).
     - **ship_id (line 23):** Select the ship layout (1 for ship_layout or 2 for bonus_ship_layout).
     - **steps (line 24):** Specify the number of steps for bot_4 to perform the risk map (steps >= 0).
     - **D (line 25):** Set the dimension of the square grid (D >= 3).
     - **q (line 26):** Set the flammability (0 <= q <= 1).
     - **display_dimension (line 27):** Set the screen width and height of the display (display_dimension > 0 in pixels).

5. **Run the Project**

   - Open a terminal and navigate to the final directory:

     - `cd ./final/`

   - Run the main script:

     - `py ./main.py`
